# Assets do Projeto

Este diretório contém recursos visuais e arquivos estáticos do projeto.

## 📁 Estrutura

```
assets/
├── README.md              # Este arquivo
├── images/                # Imagens e screenshots
│   ├── logo.png
│   ├── architecture.png
│   └── screenshots/
├── diagrams/              # Diagramas e fluxogramas
│   ├── pipeline-flow.png
│   ├── data-architecture.png
│   └── infrastructure.png
├── icons/                 # Ícones e elementos visuais
│   ├── favicon.ico
│   └── app-icons/
└── docs/                  # Documentos visuais
    ├── presentations/
    └── reports/
```

## 🎨 Tipos de Assets

### Imagens (`images/`)
- Logo do projeto
- Screenshots da aplicação
- Imagens de demonstração
- Capturas de tela de dashboards

### Diagramas (`diagrams/`)
- Arquitetura do sistema
- Fluxo de dados
- Infraestrutura
- Modelos de dados

### Ícones (`icons/`)
- Favicon do projeto
- Ícones da aplicação
- Elementos visuais

### Documentos (`docs/`)
- Apresentações
- Relatórios visuais
- Documentação gráfica

## 📋 Convenções

- Use formatos otimizados (PNG, SVG, WebP)
- Mantenha resolução adequada
- Use nomes descritivos
- Organize por categorias

## 🔧 Formatos Suportados

- **Imagens**: PNG, JPG, SVG, WebP
- **Diagramas**: PNG, SVG, PDF
- **Ícones**: ICO, PNG, SVG
- **Documentos**: PDF, PPTX

## 📚 Uso

Os assets são utilizados em:
- Documentação (`docs/`)
- README do projeto
- Apresentações
- Dashboards
- Interface da aplicação
