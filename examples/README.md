# Exemplos de Uso

Este diretório contém exemplos práticos de como usar o Pipeline de Dados.

## 📁 Estrutura

```
examples/
├── README.md              # Este arquivo
├── basic_usage.py         # Exemplo básico de uso
└── notebooks/             # Jupyter notebooks de exemplo
```

## 🚀 Como usar

1. **Exemplo Básico**: Execute `python examples/basic_usage.py`
2. **Notebooks**: Abra os notebooks no Jupyter ou Databricks
3. **Configuração**: Ajuste as variáveis de ambiente conforme necessário

## 📋 Pré-requisitos

- Python 3.9+
- Dependências instaladas (`pip install -r requirements.txt`)
- Configuração do Azure (credenciais, Databricks, etc.)

## 🔧 Configuração

Antes de executar os exemplos, configure as variáveis de ambiente:

```bash
export AZURE_STORAGE_ACCOUNT="your-storage-account"
export AZURE_STORAGE_KEY="your-storage-key"
export DATABRICKS_HOST="your-databricks-workspace"
export DATABRICKS_TOKEN="your-databricks-token"
```
